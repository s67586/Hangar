Hangar 裝置牆

這些不在管理範圍內 —— 掃描看得到它們在這個網段上，但沒有對應的設定。

牆上的狀態是什麼意思

ready
adb 是 device，可以 build 也可以投影
agent_only
adb 進不去，但手機裡的 agent 還答得出話 —— 看得到、管不動
no_adb
連得到但 adb 不是 device，多半是手機重開機把 5555 弄丟了
unauthorized
這台 hub 還沒被那支手機授權過（要有人在手機上按「一律允許」）
unknown
只從掃描看到它，hangar list 那邊沒資料（那次輪詢多半失敗了）
offline
手機不在線上
unmanaged
掃得到但沒設定過。沒開偵錯的手機 adb 完全碰不到，所以只有 IP 與 MAC —— 機型與電量要等它裝上 agent

電池那一行的插著沒在充是 Android 的 not_charging： 線插著、但電沒有在進去（溫度過高、充電保護、或那個孔供電不夠），跟放電中 的沒插電是兩回事。停在高電量是正常的保護機制；停在低電量代表那條線或那個孔有問題， 所以低電量提醒把它算成「要充電」。

這頁不會去動手機，也不會去改設定檔 —— hub 上沒有任何會動手機的端點。

投影按鈕

按鈕叫的不是 hub，是你自己這台電腦：hub 跑起來的視窗開在那台常駐機器上， 沒有人看得到。所以每台要按的電腦得自己跑一支 helper，按鈕才叫得動它 —— ./helper/hangar_helper.py --hub 這一頁的網址，然後照它印的連結進來一次。

第一次投某一支手機，那台電腦仍然要跑過 hangar setup： adb 授權綁的是每台電腦自己的金鑰，按鈕省不掉這一步。
