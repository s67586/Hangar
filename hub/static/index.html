ready 可以 adb 進去（build／投影都行）｜ no_adb 連得到但 adb 不是 device，多半是手機重開機把 5555 弄丟了｜ unauthorized 這台 hub 還沒被手機授權｜ agent_only adb 進不去，但手機裡的 agent 還答得出話（看得到、管不動）｜ offline 手機不在線上｜ unknown 只從掃描看到它，hangar list 那邊沒資料（那次多半掛了）｜ unmanaged 掃到但沒設定過 —— 沒開偵錯的手機只看得到 IP 與 MAC， 機型與電量要等手機端的 agent app。
這頁是唯讀的，不會去動手機或設定檔。
